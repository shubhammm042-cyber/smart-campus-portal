# CampusCare — Student Help Portal
A responsive front-end project for CSE326 Internet Programming, built with HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Submit a sample issue in the form. Reports are stored in your browser's localStorage.

## Features
- Responsive layout for phone and laptop
- Issue submission form with required-field checks
- Categories and campus location
- Recent reports and status filtering
- Browser-local persistence
- Demo mode to restore sample reports

## Important project limitation
This is a front-end demonstration. It does not connect to a college server, notify staff, or provide real user authentication. For a production version, add a backend, database, access control, and privacy/security review.

## Suggested presentation
**Problem:** Students may not know where or how to report common campus issues.
**Solution:** One simple portal to submit and track reports.
**Technology:** HTML for structure, CSS for design/responsiveness, JavaScript for form handling, filtering, and browser storage.
**Future scope:** Staff login, database, image uploads, email notifications, and analytics.
